# Uber Direct (uber-direct)

Uber Direct is Uber's last-mile delivery-as-a-service platform that lets merchants dispatch couriers via the Uber network for on-demand and scheduled deliveries.

## APIs

### Uber Direct API

Uber Direct API (DaaS) for quoting, creating, tracking, and managing deliveries through the Uber courier network. Includes Direct, Organizations, Courier Pick & Pack, Refund, and Business Location Management APIs plus webhook subscriptions.

- **Human URL:** [https://developer.uber.com/docs/deliveries](https://developer.uber.com/docs/deliveries)
- **Base URL:** `https://api.uber.com/v1/customers`
